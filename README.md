# .gitignore 生成器

一个纯前端的单文件 .gitignore 生成工具，勾选需要的技术栈模板即可实时组合生成 .gitignore 文件，无需安装、无需后端、无任何外部依赖。

## 功能特性

- ✅ **40+ 技术栈模板**：覆盖主流语言、前端框架、IDE / 编辑器、操作系统、构建工具等。
- 🔍 **中文 / 英文搜索过滤**：快速定位所需模板。
- 🗂️ **分类分组展示**：语言、前端、IDE、系统、工具、其他，结构清晰。
- ⚡ **实时预览**：左侧勾选，右侧即时生成带分隔注释的 .gitignore 内容。
- 📋 **一键复制**：将生成的规则复制到剪贴板。
- ⬇️ **一键下载**：直接下载 `.gitignore` 文件。
- 🛠️ **自定义追加规则**：在末尾追加自己的特殊规则。
- 🌓 **深浅色主题切换**：支持浅色 / 深色模式，自动保存偏好。
- 💾 **状态持久化**：选中的模板与自定义规则自动保存到 localStorage，刷新不丢失。

## 使用方式

直接用浏览器打开 `index.html` 即可：

```bash
open index.html        # macOS
# 或拖入浏览器
```

## 技术说明

- 单一 HTML 文件，原生 HTML / CSS / JavaScript，零依赖、零构建步骤。
- 所有模板与生成逻辑均在浏览器本地完成，不上传任何数据。
